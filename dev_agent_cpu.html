Dev agent

An AI that writes code, runs it, finds bugs and fixes them. It runs entirely inside this page, on your own processor, so no graphics card or hardware acceleration is needed. No API key, no account, nothing to install.

Starting…

The first start downloads the model once (0.4 to 2 GB depending on the size you pick) and keeps it for next time. Needs an internet connection for that first download. It runs on the CPU, so expect a few words per second; the 0.5B model is fastest, the 3B model is smartest. Smaller models make more mistakes.

Paste code with a bug, or describe something to build.
